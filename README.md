Practice with Playwright

✌️Hi there! Welcome to my project with Playwright.

The Internet (https://the-internet.herokuapp.com/) is the GitHub automation practice free website.
I finished this POM automation project with Selenium Java (https://github.com/linhln20/selenium-java). I continue practicing with Playwright, the same test cases at Selenium Java.
The project focus on Chromium for CI/CD testing (save time to install drivers on GH Actions).

I am serious about becoming a skilled and reliable tester; I am trying to improve my skills daily with automation tools like Playwright.
The test cases and scenarios described here reflect the initial scope of the project. Since then, many more test scripts and scenarios have been implemented within the codebase that may not be explicitly listed in this README. Feel free to explore the code to see the full coverage!

I'll update the special cases if I catch them in the future.
